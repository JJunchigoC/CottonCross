# CFX-Net v1 / v2 的取舍准则（在看到 v2 的验证交叉 F1 之前写定）

## 为什么需要这份文件

第一版 CFX-Net 的 OCA 交叉先验增益学成了约 0（−0.075 / +0.010 / −0.019），说明该通路没有被使用。据此做了第二版：方向能量取通道最大值、按图标准化、零初始化 1×1 卷积注入、注意力融合改为门控残差。

**改动的动机只针对交叉检测通路。** 因此在比较两版时，必须事先声明用哪个数字来决定，否则就是看完结果再挑对自己有利的标准。

## 准则（此刻写定，此时 v2 的验证交叉 F1 尚未算出）

1. **决定指标：合成验证集上的交叉点 F1**（由 `scripts/tools/tune_threshold.py` 在 val 划分上扫阈值得到，取三个种子的均值）。选它的理由是：OCA 模块存在的目的就是改善交叉检测，诊断出的缺陷也在这条通路上。
2. **辅助指标（不用于决定，只用于如实报告）**：训练期使用的验证分数（占据 Dice 与中心线 Dice 的均值）。
3. **判定**：
   - v2 的验证交叉 F1 **高于** v1 → 采用 v2，并在文档中如实写明验证分数是否因此下降；
   - v2 的验证交叉 F1 **不高于** v1 → **放弃 v2，恢复 v1**（检查点已归档在 `runs/legacy/cfxnet_v1_s*`），并把这次修改作为一次失败的尝试写进文档。
4. **测试集在这一步完全不参与。**
